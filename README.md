# InSureRance-Amaga-ShayndelMizy-G7
 An Insurance Literacy Learning and Analytics System for Students and Young Adults

# Proposed Technology / Platform: Python, Django, PostgreSQL/supabase

# Target Users/Beneficiaries
•	Students and Young Adults – access insurance lessons, take quizzes and assessments, and view their learning progress and insurance literacy results.
•	Administrator – manages learning content, user records, and overall system analytics.

# Project Description
InSureRance is a web-based learning and analytics system designed to help students and young adults understand basic insurance concepts through organized lessons, quizzes, real-life scenarios, an Insurance Personality Quiz, and a Scam Checker. The system records users' quiz scores, completed lessons, activities, and assessment results in a relational database.

The stored data is analyzed and presented through a dashboard where users can view their Insurance Literacy Level, learning progress, strengths, and areas that need improvement. Administrators can also manage learning content and view overall user performance and learning analytics.

# Problem Statement
Many students and young adults have limited knowledge about basic insurance concepts because insurance information can be difficult to understand and is often scattered across different sources. Because of this, users may have difficulty knowing how much they understand about insurance and which topics still need improvement.

There is also no organized way for users to track their insurance learning activities, quiz performance, and assessment results. InSureRance addresses this problem by storing learning records in one system and analyzing the data through a dashboard that helps users understand their current level of basic insurance knowledge.

# General Objective
To develop a web-based insurance literacy learning and analytics system that helps students and young adults understand basic insurance concepts and monitor their learning performance.

# Specific Objectives
1. To allow users to create and manage their accounts and personal profiles.
2. To allow the administrator to create, view, update, and manage insurance topics, lessons, quizzes, questions, scenarios, resources, and badges.
3. To record users' quiz attempts, scores, completed lessons, and assessment results in a relational database.
4. To provide insurance learning activities such as quizzes, scenario-based learning, an Insurance Personality Quiz, and a Scam Checker.
5. To calculate and display the user's Insurance Literacy Level based on completed quiz results.
6. To allow the administrator to search and filter user records, lessons, quizzes, and quiz attempts.
7. To provide users with an analytics dashboard showing their learning progress, strengths, weak areas, and quiz performance.
8. To generate summary views for the administrator showing overall user performance, lesson completion, and assessment results.
